# Vaishnav Shinde — Complete Project Index

Vaishnav Shinde has built 4 major projects. Below is a summary of each:

## 1. MediChain Intelligence (Blockchain Healthcare & Clinical Triage System)
A privacy-first, decentralized digital health platform combining Ethereum/Sepolia blockchain, IPFS storage, and machine learning for clinical record management. Features include patient consent via QR codes, AES-128 encrypted records stored on IPFS, Solidity smart contracts for audit trails, and Random Forest ML models for triage prediction and hospital load forecasting. Built with Vite React, FastAPI, Hardhat, Web3.py, Ethers.js, and SQLite.

## 2. Guard Up / IIDS (Intelligent Intrusion Detection System)
A computer vision surveillance system designed for edge deployment (Raspberry Pi). Uses a dual-pipeline architecture: Tier 1 motion filtering with OpenCV, Tier 2 deep learning verification with a custom MobileNetV2 transfer-learned classifier, and YOLOv8 nano for real-time object/weapon detection. Features a Streamlit HUD dashboard with Plotly charts, Telegram alert notifications, and handheld threat detection via bounding box overlap analysis. Built with TensorFlow, OpenCV, YOLOv8, Streamlit, and Python.

## 3. HirePulse Pivot (AI-Powered Job Aggregator & Career Recommendation System)
A full-stack job aggregation and resume analysis platform. Scrapes job postings from Adzuna API, vectorizes content with Google Gemini embeddings (768d), stores in Supabase PostgreSQL with pgvector, and uses a dual-engine RAG pipeline for semantic job matching and career coaching via Gemini 2.0 Flash Lite. Features JWT authentication, resume parsing, skill gap analysis, and automated match emails via Resend API. Built with FastAPI, React + Vite, Supabase, and LangChain.

## 4. XAUUSD M15 Mean Reversion ML Framework (Market Pattern Model)
A quantitative trading framework for gold (XAUUSD) on 15-minute timeframes. Implements Ornstein-Uhlenbeck mean reversion modeling, Hurst exponent analysis, Parkinson and Garman-Klass volatility estimators, Triple Barrier Method labeling, and a stacked ensemble ML classifier (LightGBM + XGBoost with Logistic Regression meta-learner). Features purged walk-forward cross-validation, liquidity sweep detection, fair value gap analysis, and Forex Factory news calendar integration. Built with Python, MetaTrader 5, LightGBM, XGBoost, and Scikit-Learn.
